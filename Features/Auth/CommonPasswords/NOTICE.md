# Third-party notices

`common-passwords.txt` holds the entries of 8 or more characters from `10_million_password_list_top_100000.txt` in Andrew Lock's CommonPasswordsValidator, at commit 4054ab96e4c51a88e639fd094096c3b34c22ad2e: https://github.com/andrewlock/CommonPasswordsValidator

Lock took that file from the SecLists 10 million passwords list, top 100,000: https://github.com/danielmiessler/SecLists. SecLists has edited its copy since, now `xato-net-10-million-passwords-100000.txt`, so the two no longer match line for line.
